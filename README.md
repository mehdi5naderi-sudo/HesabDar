# ربات حسابدار شخصی تلگرام

ربات حسابداری مینیمال روی Cloudflare Workers و D1. پیام‌های تراکنش در چت باقی می‌مانند و ربات فقط یک پیام «مانده فعلی» را ویرایش می‌کند؛ برای هر تراکنش پیام تأیید جداگانه نمی‌فرستد.

## راه‌اندازی

۱. در Cloudflare مسیر **Workers & Pages → D1 → hesabdar-db → Console** را باز کن.
۲. اگر جدول‌ها هنوز ساخته نشده‌اند، محتوای `schema.sql` را اجرا کن. این نسخه امن است و جدول‌ها یا تراکنش‌های موجود را حذف نمی‌کند.
۳. در **Settings → Variables and Secrets** این دو Secret را تنظیم کن:
- `TELEGRAM_BOT_TOKEN` — توکن BotFather
- `WEBHOOK_SECRET` — یک رشته تصادفی بلند
۴. آدرس `https://نام-worker.workers.dev/setup/مقدار-WEBHOOK_SECRET` را در مرورگر باز کن تا Webhook ثبت شود.

## استفاده

- `واریز 1000` یا `واریز ۱۰۰۰` — ثبت واریز
- `برداشت 500` یا `برداشت ۵۰۰` — ثبت برداشت

ربات پیام‌های نامرتبط یا ورودی‌های نامعتبر را نادیده می‌گیرد تا چت شلوغ نشود. پیام مانده تا حد امکان در همان پیام قبلی ویرایش می‌شود، نه اینکه هر بار پیام تازه‌ای بسازد.

## نکته مهم درباره اطلاعات قبلی

**هیچ‌وقت فایل schema.sql قدیمی دارای دستورهای `DROP TABLE` را دوباره اجرا نکن.** آن دستورها تاریخچه حسابداری و شناسه پیام مانده را پاک می‌کنند.
